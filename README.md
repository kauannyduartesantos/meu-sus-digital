# Meu SUS Digital

## Sobre o projeto

Este projeto acadêmico apresenta uma proposta de redesign da interface do Meu SUS Digital, com foco em melhorar a usabilidade, a acessibilidade e a organização das informações.

**Descrição do projeto:**  
O presente trabalho apresenta o desenvolvimento da interface e arquitetura de informação do portal "Meu SUS Digital", um ecossistema focado na centralização de serviços de saúde pública. O objetivo central do projeto foi criar uma plataforma inclusiva e resiliente, capaz de atender a perfis distintos de usuários (personas), desde nativos digitais que buscam agilidade até idosos com limitações de acuidade visual e familiaridade tecnológica. Para tanto, utilizou-se a metodologia de design fundamentada no framework CRAP (Contraste, Repetição, Alinhamento e Proximidade) e estratégias de engenharia de software como Mobile-First, UI Otimista e Offline-First. Os resultados da documentação de interface, que evoluíram de wireframes estruturais para protótipos de alta-fidelidade, demonstram um sistema com baixa carga cognitiva, alta acessibilidade e fluxos de navegação simplificados. O projeto conclui que a união entre design centrado no usuário e estratégias de desenvolvimento otimizadas é fundamental para a democratização do acesso aos serviços digitais de saúde no Brasil. 

## Objetivos

- Melhorar a organização visual das informações.
- Facilitar a navegação entre as funcionalidades.
- Considerar recursos de acessibilidade.
- Tornar os fluxos de consulta e agendamento mais simples.

## Funcionalidades

- Dashboard
- Consultas e agendamentos
- Meus exames
- Vacinas
- Medicamentos
- Prontuário
- Token Fila
- Telemedicina
- Perfil e configurações de acessibilidade
